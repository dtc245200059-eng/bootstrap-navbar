Thanh điều hướng chuyên nghiệp, đáp ứng hoàn hảo trên mọi thiết bị (Responsive: Mobile, Tablet, Desktop) với đầy đủ Brand, Navigation Links, Dropdown Menu và Hamburger Toggler.

Khám Phá Tính Năng Xem Chi Tiết Mã Nguồn
100% Responsive

Sử dụng navbar-expand-lg và nút navbar-toggler giúp menu tự động thu gọn thành Hamburger Menu trên màn hình điện thoại.

Dropdown Menu

Hỗ trợ menu đa cấp tiện lợi thông qua lớp dropdown-menu kết hợp với Bootstrap JavaScript Bundle.

Tối Ưu & Tinh Gọn

Nhúng trực tiếp qua CDN chính thức của Bootstrap 5.3, không yêu cầu cài đặt phức tạp, tốc độ tải trang cực nhanh.

Hướng Dẫn Kiểm Tra Bài Thực Hành

  • 1. Kiểm tra Dropdown: Nhấp vào mục Services trên Navbar để xem danh sách thả xuống gồm Web Design và SEO.
  • 2. Kiểm tra Responsive Mobile: Thu nhỏ cửa sổ trình duyệt hoặc nhấn phím F12 (chuyển sang chế độ Mobile view) để thấy nút 3 gạch Toggler. Bấm vào nút để mở/đóng menu.
  • 3. Trạng thái Active: Mục Home được đánh dấu active thể hiện trang hiện tại.
